ShopSphere Cloud Service Classification
Frontend Hosting (Vercel):

Classification: PaaS (Platform as a Service)

Reason: Vercel abstracts the underlying infrastructure, servers, and build environments, allowing us to deploy and host the frontend web application directly from static files and build code without managing virtual machines.

Backend Hosting (Vercel Serverless Functions):

Classification: PaaS (Platform as a Service) / Serverless

Reason: Vercel manages the execution runtime, automatically scaling backend API endpoints and handling OS updates without requiring manual server provisioning or OS configuration.

Database Hosting (Supabase PostgreSQL):

Classification: BaaS (Backend as a Service) / PaaS

Reason: Supabase provides a fully managed PostgreSQL database with instant APIs, authentication, and database management tools without requiring us to configure or maintain raw database servers.
